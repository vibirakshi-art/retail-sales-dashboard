# 🛒 Retail Sales Analysis Dashboard Using Power BI

## 📌 Project Overview

The **Retail Sales Analysis Dashboard** is a business intelligence project developed using Microsoft Power BI to analyze retail sales data and generate actionable insights through interactive visualizations.

This dashboard helps businesses understand:

* Customer purchasing behavior
* Product category performance
* Revenue trends
* Customer demographics
* Sales performance metrics

The project demonstrates how raw retail data can be transformed into meaningful business insights for better decision-making.

---

# 📊 Dashboard Features

### ✅ KPI Cards

The dashboard includes important business KPIs such as:

* **Total Revenue**
* **Average Sales**
* **Maximum Quantity Purchased**
* **Unique Products Count**
* **Customer Count by Gender**

---

# 📈 Visualizations Included

### 1. Pie Chart – Quantity by Product Category

Displays sales quantity distribution among:

* Clothing
* Electronics
* Beauty

### 2. Bar Chart – Transaction Count by Gender

Compares purchase transactions between male and female customers.

### 3. Column Chart – Age by Gender

Analyzes customer age distribution based on gender.

### 4. Donut Chart – Price Per Unit by Product Category

Shows contribution of product pricing across categories.

### 5. Area Chart – Total Revenue by Product Category

Displays category-wise revenue generation.

### 6. Interactive Slicers

* Product Category Filter
* Customer ID Filter
